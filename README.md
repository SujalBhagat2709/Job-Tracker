# Job Tracker

## Overview

A dynamic job tracking tool that fetches live remote job opportunities based on skills.

---

## Features

- Live job search
- Skill-based filtering
- Remote job discovery
- Real-time API data

---

## Files

- `fetch_jobs.py`
- `filter_jobs.py`

---

## Installation

```bash
pip install requests
```

---

## Usage

```bash
python fetch_jobs.py
python filter_jobs.py
```

---

## Example

```text
Enter skill: python

Title: Backend Python Developer
Company: ABC Tech
Location: Worldwide
```
